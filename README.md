# نظام الكول سنتر (PHP) + بوت تليجرام + تتبع المناديب

## المتطلبات
PHP 8.0+ مع `pdo_sqlite` و `curl` (متوفرة في أغلب الاستضافات). **HTTPS إجباري** لتليجرام ولإرسال الموقع من المتصفح.

## التشغيل على استضافة عادية (cPanel وغيرها)
1. ارفع كل الملفات في مجلد (مثلاً `public_html/callcenter`).
2. تأكد أن مجلد `data/` قابل للكتابة (chmod 775). قاعدة البيانات تتكوّن تلقائياً  أول مرة.
3. افتح `https://موقعك/callcenter/` وادخل بـ `admin / admin123` ثم **غيّر كلمة المرور فوراً** من «المستخدمون والصلاحيات».
   التركيب الجديد بيبدأ **فاضي** وفيه 3 حسابات: `admin / admin123` (مدير)، `morning / 1234` (الشيفت الصباحي)، `evening / 1234` (الشيفت المسائي). في صفحة الدخول أزرار سريعة لكل واحد. **غيّر كلمات المرور الثلاثة**.

## التشغيل على Railway / Docker
المشروع فيه `Dockerfile` جاهز. ارفعه على GitHub واربطه بـ Railway، وأضف **Volume** مربوط على `/app/data` علشان قاعدة البيانات ما تضيعش عند كل نشر.
متغيرات بيئة اختيارية: `TG_TOKEN`, `BASE_URL`, `TG_SECRET`, `DB_PATH`.

## ربط تليجرام
1. من @BotFather: `/newbot` وخد التوكن.
2. في النظام: **إعدادات تليجرام** ← الصق التوكن ← «حفظ والتحقق» ← «تفعيل الويبهوك».
3. صفحة **المندوبون** ← «ربط تليجرام» عند كل مندوب ← سلّمه الكود (أو الرابط).
4. المندوب يبعت الكود للبوت فيظهر «مربوط ✈️».

## الأوردرات على تليجرام
عند اختيار مندوب مربوط في أوردر جديد (أو تغيير المندوب) يوصله الأوردر فوراً برقم العميل والعنوان وزر الخرائط،
وبأزرار **«خرجت بالأوردر»** و **«تم التسليم»** — وبتتسجل تلقائياً في النظام (حالة + وقت الخروج والعودة).

## تتبع المناديب
صفحة **تتبع المناديب**: خريطة OpenStreetMap + قائمة بالمناديب، لون النقطة حسب حداثة الموقع، وعدد الأوردرات الجارية، وضغطة على المندوب تعرض مساره آخر 3 ساعات.
المندوب عنده طريقتان لإرسال موقعه:
- **تليجرام:** 📎 ← الموقع ← «مشاركة الموقع الحي» ← 8 ساعات (موصى بها).
- **رابط المتصفح:** من نافذة «ربط تليجرام» تلاقي رابطاً خاصاً بالمندوب، يفتحه ويضغط «ابدأ» ويسيب الصفحة مفتوحة.

## ما تغيّر عن النسخة القديمة
- البيانات في قاعدة SQLite على السيرفر (مشتركة بين كل الأجهزة) بدل localStorage.
- كلمات المرور مشفّرة، وحماية CSRF، وكل الاستعلامات prepared statements.
- المندوب في الأوردر مربوط بـ id (مش اسم نصي)، وأُضيفت حالة للأوردر (بانتظار/خرج/تم التسليم). الأوردرات القديمة كلها «تم التسليم».
- ترقيم صفحات للأوردرات (100/صفحة) بدل حد الـ 300 صف، والتصدير CSV يشمل كل النتائج.
- صلاحية جديدة: «تتبع المناديب».

## تحديث: الشيفتات وتكويد العملاء
- **الشيفت:** كل مستخدم ليه شيفت (صباحي / مسائي / الكل). مستخدم الشيفت بيشوف بيانات شيفته بس ومفيش عنده مبدّل؛ المدير والمستخدم «الكل» عندهم مبدّل أعلى القائمة الجانبية. الشيفت بيتطبّق على كل الصفحات: الرئيسية، الأوردرات، العملاء، تقرير الفترة، وحسابات المناديب (أوردرات ودفعات كل شيفت لوحدها).
  الدفعات بقى ليها شيفت، والدفعات القديمة (قبل التحديث) بتظهر في «الكل» فقط. الأوردر الجديد بياخد الشيفت المختار تلقائياً.
- **العملاء:** سجل بكود تلقائي (C0001…) واسم ورقم وعنوان. العملاء الحاليين (269) اتكوّدوا تلقائياً من أوردراتك بعناوينهم، والأسماء فاضية تقدر تكمّلها من «تعديل».
  في فورم الأوردر: اكتب الرقم أو الاسم أو الكود وهيقترح عليك العملاء ويملّى الاسم والعنوان، والعميل الجديد بيتكوّد أول ما تحفظ الأوردر.
- الترقية تتم تلقائياً على قاعدة البيانات الحالية من غير ما تفقد أي بيانات.

## مسح البيانات التجريبية
من «إعدادات تليجرام» (آخر الصفحة): زر «مسح كل البيانات» بيمسح الأوردرات والعملاء والمناديب والدفعات وسجل المواقع، ويبدأ الترقيم من جديد. المستخدمين وتوكن البوت بيفضلوا.

## ربط الأوردرات بالعملاء + فصل الشيفتين
- كل أوردر مربوط بسجل العميل (customer_id). العميل واحد في الشيفتين: اسمه وكوده وعنوانه مشتركين، والأوردرات والإحصائيات منفصلة لكل شيفت.
- المناديب والعملاء بياناتهم مشتركة بين الشيفتين، لكن أوردرات المندوب ودفعاته وحسابه بتتفصل لكل شيفت.
- مستخدم الشيفت لا يرى ولا يعدّل أوردرات/دفعات الشيفت الآخر، وحتى الأوردرات الجارية في خريطة التتبع بتتفلتر بشيفته. رقم البون بيتفحص تكراره داخل نفس الشيفت فقط.
- عميل له أوردرات لا يمكن حذفه (عدّل بياناته).

## النشر على Railway
1. ارفع المشروع على GitHub (الـ `.gitignore` بيمنع رفع قاعدة البيانات).
2. Railway ← New Project ← Deploy from GitHub repo. هيكتشف الـ `Dockerfile` تلقائياً.
3. من تبويب **Volumes** أضف Volume واعمل Mount Path = `/data`. (بدونه قاعدة البيانات بتتمسح مع كل نشر!)
4. من **Settings ← Networking** اضغط Generate Domain.
5. افتح الرابط وادخل بـ `admin / admin123`، ثم «إعدادات تليجرام»: الصق التوكن ← «تفعيل الويبهوك» (الرابط HTTPS تلقائياً).
متغيرات اختيارية في Variables: `TG_TOKEN`, `BASE_URL`.

## تثبيت التطبيق على الموبايل (PWA)
الموقع بقى قابل للتثبيت: أندرويد (Chrome) ← ⋮ ← «تثبيت التطبيق»، آيفون (Safari) ← مشاركة ← «إضافة إلى الشاشة الرئيسية». يحتاج HTTPS (Railway يوفره).
